# MDX 是什么？

`.mdx` 可以理解为 **Markdown + JSX**：普通文字继续用 Markdown 写，需要动态内容时，可以直接使用 JavaScript 表达式或导入组件。

<MdxCallout title="先记住这一句话">
  <p>Markdown 负责可读性，组件负责交互和复用，MDX 把两者放进同一个文件。</p>
</MdxCallout>

## 1. 文件的基本结构

一个 MDX 文件通常包含三部分：

1. 文件顶部的 YAML frontmatter，用于标题、日期、标签等元数据。
2. 中间的 Markdown 正文。
3. Markdown 之间的 import、变量和组件表达式。

本页的 frontmatter 会被博客的文章集合读取，并自动显示在文章标题下方。

## 6. 什么时候用 MDX？

如果文章只是标题、段落、图片和代码，继续用 `.md` 更简单。

如果文章需要以下能力，`.mdx` 会更合适：

- 在正文中插入提示框、统计卡片或自定义组件。
- 根据变量或条件决定页面内容。
- 使用数组生成重复内容。
- 把文章和交互式演示放在同一个文件里。

## 总结

MDX **不是另一种完全不同的 Markdown**，而是在 Markdown 上增加了组件和 JavaScript 能力。本项目现在同时支持 `.md` 和 `.mdx`，旧文章不需要修改，新文章可以按需要选择格式。
